# Simple CLI Calculator

A straightforward, interactive Command Line Interface (CLI) calculator built with Python. This application allows users to perform standard arithmetic operations seamlessly with built-in error handling for invalid inputs and division by zero.

## Features

* **Basic Arithmetic Operations:** Supports Addition, Subtraction, Multiplication, and Division.
* **Robust Input Validation:** Gracefully handles non-numerical inputs without crashing.
* **Safe Division:** Detects and prevents runtime crashes caused by dividing a number by zero.
* **Looping Interface:** Keeps running until you explicitly choose to exit.
